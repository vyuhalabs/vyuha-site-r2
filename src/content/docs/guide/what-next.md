With one run read, decide how much you want to decide. Set the tier of each kind of decision, set budgets and spending thresholds, and look at your Inbox to see what is waiting for you.

The stop button halts every run within two seconds. It is there when you want everything to stop first and be understood after.

The [model page](../model/) explains each of these in plain words, and the [FAQ](../faq/) answers the questions people ask first.
