Choose a small change you can check by looking at it. Write what should change, then list the acceptance criteria: each one a sentence that can be seen to hold or not, such as "the export has only the rows in the chosen date range".

An agent picks the issue up, works on a branch of its own and attaches evidence as it goes. When it finishes, the issue moves on to review.

You do not need to watch. Decisions that need you arrive in your Inbox, and the board shows where every issue is.
