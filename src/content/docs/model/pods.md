title: "Pods"
summary: "A pod is the group of agents a project's stage needs, hired by role."
---

A pod is the group of agents attached to a project and its playbook. Each stage needs certain roles, and the pod holds them. A build stage might need a delivery lead, engineers, a code reviewer and a QA engineer.

The lead plans the work and splits it into issues. The others pick the issues up, review them and verify them. Adding an agent to a pod is a hire, and a hire is a decision, so it has a tier like any other.
